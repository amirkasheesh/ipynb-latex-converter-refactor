# ipynb-latex-converter-refactor

Веб-приложение для обработки файлов Jupyter Notebook (`.ipynb`) и преобразования их в документы LaTeX (`.tex`) и PDF.

Проект является модернизацией базовой версии приложения. Основная цель — сделать удобный веб-интерфейс для настройки содержимого итогового документа, редактирования LaTeX-кода и генерации PDF.

## Возможности

- загрузка одного или нескольких `.ipynb` файлов;
- проверка корректности загружаемых файлов;
- выбор ячеек, которые попадут в итоговый документ;
- настройка включения исходного кода и результатов выполнения;
- выбор шаблона оформления документа:
  - стандартный;
  - статья;
  - отчет по ГОСТ;
- выбор режима мультифайловой конвертации:
  - объединение всех файлов в один `.tex`;
  - создание нескольких `.tex` файлов с главным файлом через `\include{}`;
- предварительный просмотр результата;
- просмотр и ручное редактирование LaTeX-кода;
- подсветка синтаксиса LaTeX в редакторе;
- пересборка PDF из отредактированного LaTeX-кода;
- отображение лога ошибок LaTeX-компиляции;
- скачивание результата в формате `.tex` или `.pdf`;
- светлая и темная тема интерфейса;
- сохранение пользовательских настроек в браузере.

## Локальный запуск

Для запуска проекта нужен установленный Docker.

В корне проекта выполнить:

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресам:

```text
Frontend: http://localhost:3000
Backend API: http://localhost:8000/docs
```

Первый запуск может быть долгим, так как backend-образ устанавливает LaTeX-пакеты.

## Основной сценарий работы

1. Открыть главную страницу приложения.
2. Загрузить один или несколько файлов `.ipynb`.
3. Выбрать нужные ячейки.
4. Настроить параметры конвертации:
   - шаблон оформления;
   - тему интерфейса;
   - тип выходного файла;
   - режим мультифайловой конвертации;
   - фон ячеек с кодом;
   - отступы;
   - удаление комментариев;
   - отображение номеров ячеек.
5. Нажать кнопку «Сконвертировать».
6. Проверить результат во вкладках LaTeX и PDF.
7. При необходимости изменить LaTeX-код во встроенном редакторе.
8. Нажать «Обновить PDF», чтобы пересобрать документ после ручных правок.
9. Скачать готовый файл.

## Работа с несколькими файлами

Приложение поддерживает загрузку нескольких `.ipynb` файлов.

Доступны два режима:

1. **Один итоговый `.tex` файл**  
   Все выбранные ячейки из всех загруженных файлов объединяются последовательно в один документ.

2. **Несколько итоговых `.tex` файлов**  
   Для каждого загруженного `.ipynb` создается отдельный `.tex` файл, а главный документ подключает их через директивы `\include{}`.

Настройки конвертации применяются ко всем выбранным файлам.

## Работа с LaTeX-редактором

После конвертации во вкладке LaTeX отображается сгенерированный TeX-код.

Пользователь может:

- просмотреть LaTeX-код;
- вручную изменить его;
- использовать подсветку синтаксиса;
- пересобрать PDF нажатием кнопки «Обновить PDF».

Если в LaTeX-коде есть ошибка, приложение покажет понятное сообщение и лог компиляции.

## Проверка ошибок

Приложение обрабатывает основные ошибочные ситуации:

- загружен не `.ipynb` файл;
- файл не является корректным JSON;
- файл не содержит список ячеек `cells`;
- размер файла превышает допустимый лимит;
- переданы некорректные параметры конвертации;
- выбран некорректный шаблон оформления;
- PDF не удалось собрать из-за ошибки LaTeX.

В таких случаях пользователь получает уведомление с описанием проблемы.
