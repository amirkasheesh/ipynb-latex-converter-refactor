# Общая информация

Репозиторий содержит учебный проект: веб-приложение для обработки файлов Jupyter Notebook (`.ipynb`) и подготовки результата в издательских форматах LaTeX (`.tex`) и PDF.

Проект начат на основе дипломной работы:
https://github.com/Maxim424/ipynb-latex-converter

Далее прототип был перенесён в данный репозиторий и **развивается/рефакторится мною** (см. историю коммитов).

## Цели доработки

Планируемые изменения и функциональность включают:
- загрузку `.ipynb` и проверку корректности структуры ноутбука;
- выборочную обработку ячеек (Markdown/Code/Output) и настройку включения Output;
- конвертацию в `.tex` и/или `.pdf`;
- редактирование LaTeX-текста и предпросмотр результата;
- поддержку нескольких файлов (объединение или `main.tex` + `\\include{...}`).

> Точный перечень требований определяется актуальным техническим заданием проекта.

## Статус
