# План модернизации проекта

## Цель проекта

Модернизировать веб-приложение для обработки файлов Jupyter Notebook (.ipynb) и преобразования их в LaTeX (.tex) и PDF.

## Основные блоки работ

### Backend

- Добавить строгую валидацию загружаемых .ipynb файлов
- Ограничить размер файлов до 50 МБ на сервере
- Улучшить обработку ошибок конвертации
- Возвращать пользователю понятные сообщения и логи компиляции
- Поддержать шаблоны оформления выходного документа
- Поддержать генерацию PDF из отредактированного LaTeX-кода

### Frontend

- Улучшить главную страницу
- Добавить инструкцию по работе с приложением
- Добавить явное переключение светлой и темной темы
- Добавить выбор шаблона оформления
- Добавить встроенный редактор LaTeX
- Сделать так, чтобы правки в редакторе учитывались при генерации PDF
- Улучшить отображение ошибок

### Документация

- Обновить README
- Добавить инструкцию локального запуска
- Описать основные пользовательские сценарии
- Подготовить материалы для защиты

## Ближайшие шаги

1. Проверить локальный запуск проекта.
2. Исправить README и окружение запуска.
3. Начать с backend-валидации .ipynb файлов.
4. Затем перейти к frontend-улучшениям.
